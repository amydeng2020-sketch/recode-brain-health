# 能力卡 10：营养、补充剂与激素的"靶向"原则

## R — 原文 (Reading)

> 补充剂不是越多越好。正确顺序是：先做认知体检找出缺乏，再针对性补足，并与药物和分型匹配，
> 之后复查确认。盲目堆一堆"补脑丸"既浪费钱，还可能掩盖真正的问题或产生相互作用。
>
> —— 戴尔·布来得森《终结阿尔茨海默病》营养干预模块

## I — 方法论骨架 (Interpretation)

**一个总原则：食物优先 + 检测驱动 + 医生把关。** 补剂是补"屋顶上已确认的洞"，不是替代饮食运动的主角。

1. **神经基础营养（多数人可从饮食与日照获取，确认不足再补）**：
   - **Omega-3（EPA/DHA）**：抗炎、构成神经细胞膜；目标 Omega-3 指数 >8%；优先每周 2–3 次低汞富脂鱼，补剂可选第三方检测的鱼油，服用抗凝药者需医生评估出血风险。
   - **维生素 D3**：目标 25-OH 50–80 ng/mL；常与 K2 同补（K2 帮助钙入骨，防止软组织钙化）；按基线水平定剂量并复查。
   - **B 族（B12、B6、叶酸/甲基叶酸、B1）**：降同型半胱氨酸（目标 <7–8）；老年人胃酸低、素食者、服二甲双胍/质子泵抑制剂者易缺 B12；有 MTHFR 多态性者可能需要甲基化形式（甲基叶酸、甲基 B12）。
   - **镁**（甘氨酸镁/苏糖酸镁等）、**锌**（维持 90–110 µg/dL 与合理铜锌比）、**硒**；
   - 其他常被提及：维生素 E（混合生育酚，食物优先）、辅酶 Q10/PQQ（线粒体）、NAC/谷胱甘肽（抗氧化，NAC 在部分地区按药品管理）、乙酰左旋肉碱、磷脂酰丝氨酸、假马齿苋/积雪草/银杏等神经保护草本——证据强度不一，按个体选择。
2. **肠脑与抗炎支持**：多酚（特级初榨橄榄油、浆果、姜黄素配胡椒碱/脂肪）、益生菌/益生元（菌群评估后更有针对性）、膳食纤维；疑似麸质敏感在 Cyrex 等检测和试除饮食指导下处理，不要求人人无麸质。
3. **睡眠/情绪/激素方向**：甘氨酸镁、褪黑素（短程、小剂量、定时，见 06）、L-茶氨酸、南非醉茄（注意自身免疫/甲状腺）等可讨论；
   **激素替代（雌/孕/睾酮、甲状腺、DHEA、孕烯醇酮）属医疗决策**：Ⅱ型（萎缩型）可能需要，但有血栓、激素相关肿瘤、心血管等禁忌，必须医生评估获益风险并监测，绝不自行买来吃。
4. **与分型匹配**：
   - Ⅰ型：Omega-3、姜黄素、维 D、修复肠道、控制促炎负荷更关键；
   - Ⅱ型：B12、维 D、激素与神经营养支持评估、足量蛋白与热量；
   - Ⅲ型：在脱离毒素后考虑谷胱甘肽/NAC、肝脏与结合支持（须医生主导，见 09）；
   - 同型半胱氨酸高：B12+叶酸+B6（部分加甜菜碱），复查验证。

## A1 — 书中的应用 (Past Application)

- ReCODE 首批患者的方案常包含维 D、B12/叶酸、Omega-3、镁等基础纠正——但每个人组合不同，依据是各自 cognoscopy 查出的缺乏项；数月后复查相关指标，指标改善与认知改善同步。
- 书中明确记录同型半胱氨酸升高、维 D 仅 20 上下、Omega-3 指数低的患者，针对性补充后指标归位，是"多洞齐补"的组成部分而非单一灵药。
- 商业化产品（如作者参与研发的 NeuroQ：磷脂酰丝氨酸、咖啡果提取物、积雪草、银杏、姜黄素、蜂胶）定位是"覆盖多个基础环节的配方"，并非 ReCODE 必需，也不能替代全套方案——向用户说明其商业属性。

## A2 — 触发场景 (Future Trigger) ★

1. "防痴呆该吃什么保健品？鱼油/卵磷脂/银杏/辅酶 Q10 有用吗？"
2. "我同型半胱氨酸高/维 D 低/B12 低，怎么补、补多少？"
3. "绝经后要不要补雌激素护脑？甲状腺药、睾酮呢？"
4. "补脑保健品一堆怎么选？会不会和降压药/抗凝药冲突？"

**语言信号**：补剂/保健品/营养品/鱼油/维生素/D3/B12/叶酸/同型半胱氨酸/卵磷脂/银杏/辅酶Q10/激素/雌激素/甲状腺。

**与相邻能力的区分**：
- 与 `02-认知体检` 的区别：02 负责"测出缺什么"；本卡负责"确认后怎么补、剂量逻辑、相互作用"。
- 与 `04-饮食` 的区别：本卡只处理食物难以足量或已确认缺乏时的补充；默认永远是"先食物、后补剂"。

## E — 执行步骤 (Execution)

1. **先核四件事再给任何具体建议**：年龄性别、孕哺、过敏史、基础病与**正在用的全部药物**（华法林/阿司匹林/氯吡格雷、降糖药、降压药、甲状腺素、他汀、精神类药等），以及是否已有化验单。
2. **按"三档"分层回答**：
   - 第 1 档·饮食与日照（人人优先）：富脂鱼、深色蔬菜、坚果种子、橄榄油、发酵食物、晒太阳与户外（见 04、05）。
   - 第 2 档·低风险基础纠正（建议在检测确认后，按说明书/药师建议）：维 D3+K2、B12/叶酸、Omega-3、镁——给"为什么、查哪项、目标区间、复查时间"，不给无依据的超大剂量。
   - 第 3 档·需医生处方或评估：激素、甲状腺、高剂量特定营养素、NAC/谷胱甘肽类、抗真菌/螯合、与抗凝降糖等联用的方案，一律转医生。
3. **给相互作用红旗**：鱼油/银杏/维 E + 抗凝抗血小板药 → 出血风险；补维 D 不补 K2 且大量补钙 → 钙化顾虑；
   褪黑素 + 镇静药；南非醉茄 + 甲状腺疾病/免疫抑制剂；铁剂（未确诊缺乏不要自行补铁，铁过载促氧化）。
4. **教用户做聪明消费者**：看第三方检测（IFOS 等）、有效成分与剂量而非品牌营销、不迷信"美国进口/医生代言"、警惕宣称"逆转老年痴呆"的产品（法规也不允许此类功效承诺）；一次只新增 1–2 种以便观察反应。
5. **闭环复查**：开始补充后 8–12 周复查对应指标（25-OH-D、同型半胱氨酸、Omega-3 指数等），与认知评估一起看效果，按结果加减。
- **完成标准**：用户拿到①"先食物、后检测、再补充"的正确顺序 ②与其化验/用药匹配的补充建议与红旗 ③复查安排；而不是一张购物清单。
- **判停条件**：疑似药物/补剂不良反应（出血、皮疹、肝肾异常、严重胃肠反应）、自行使用激素后不适 → 停药需咨询医生并尽快就诊。

## B — 边界 (Boundary) ★

- 本卡**不是处方**：不替代医生、药师、注册营养师的个体化方案；不给未经评估的具体处方剂量与疗程。
- 证据要诚实：除纠正明确缺乏（B12、维 D、同型半胱氨酸等）逻辑较硬外，多数"益智补剂"在健康人身上预防痴呆的高质量证据有限；银杏、辅酶 Q10、磷脂酰丝氨酸等结果不一，不能暗示确定疗效。
- 激素替代有严格禁忌与时间窗，"天然激素"≠安全；孕烯醇酮/DHEA 在部分地区是受管制物质。
- 不用补剂替代降压、降糖、抗凝、抗抑郁等规范治疗，也不建议自行停用处方药。
- 老年人多病共存、多药联用是相互作用高危人群，任何第三档方案都要医生/药师签字确认。

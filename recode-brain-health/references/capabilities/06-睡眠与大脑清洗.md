# 能力卡 06：睡眠优化与大脑"夜间清洗"

## R — 原文 (Reading)

> 深睡时大脑的类淋巴系统（glymphatic system）被激活，像夜间的清洗流水线，
> 把白天积累的代谢废物——包括 β-淀粉样蛋白——冲洗出去。长期睡不好，等于关掉了大脑的夜班保洁。
>
> —— 戴尔·布来得森《终结阿尔茨海默病》睡眠模块（B7 之一）

## I — 方法论骨架 (Interpretation)

睡眠从四条路径保护大脑：
1. **类淋巴清除**：深睡期脑脊液冲洗脑组织，带走淀粉样蛋白等废物；睡眠剥夺会让这些蛋白在脑中累积。
2. **记忆巩固**：白天学习的内容在睡眠中转移固化到长期记忆，海马"清空缓存"迎接新一天。
3. **代谢与炎症**：差睡眠升高胰岛素抵抗、皮质醇与炎症指标，直接喂养 Ⅰ型（炎症型）驱动因素。
4. **昼夜节律与激素**：规律光照—黑暗周期调控褪黑素、生长激素等"神经营养支持"，与 Ⅱ型（萎缩型）相关。

**头号可纠正杀手：阻塞性睡眠呼吸暂停（OSA）**。打鼾、白天嗜睡、晨起头痛、夜间憋醒、高血压（尤其难治性）、
颈围粗、肥胖是线索；反复缺氧和睡眠片段化显著升高痴呆风险，而它是**可筛查、可治疗**的（家用睡眠监测/多导睡眠图，CPAP 等）。

**目标**：每晚 **7–8 小时**高质量、尽量不用安眠药的连续睡眠；固定作息。

## A1 — 书中的应用 (Past Application)

- ReCODE 评估把睡眠呼吸（AHI 每小时事件数，理想 <5）列为常规项；多名患者在治疗未被诊断的睡眠呼吸暂停后，认知与情绪明显好转。
- 方案对入睡困难者给行为优先、短期/天然手段次之的路径（晨光、固定时间、呼吸放松、必要时在医生指导下用褪黑素/色氨酸/孕酮等，而非直接上镇静安眠药）。
- 照护机构案例中，戒糖、白天运动、规律作息与环境安静化后，老人焦虑与睡眠同步改善，认知回升。

## A2 — 触发场景 (Future Trigger) ★

1. "睡几个小时算够？老人觉少是不是正常？"
2. "我爸打鼾震天响、白天看电视就睡，要不要查？"
3. "长期失眠/夜醒会不会变傻？褪黑素能吃吗？"
4. "起夜多、凌晨早醒、睡前脑子停不下来怎么办？"

**语言信号**：失眠/睡不着/打鼾/睡眠呼吸暂停/早醒/夜尿/褪黑素/睡不好/白天困/OSA/CPAP/呼吸机。

**与相邻能力的区分**：
- 与 `07-压力管理` 的区别：07 处理"睡不着的心理原因与皮质醇"；本卡处理睡眠时长、节律、呼吸障碍与清洗机制。焦虑致失眠时两卡联用。
- 与 `10-营养补充` 的区别：本卡先做行为与 OSA 排查；褪黑素/镁/色氨酸等助眠补充属 10，且需医生指导。

## E — 执行步骤 (Execution)

1. **先做睡眠分诊（3 个必问）**：
   - 实际睡多久、入睡/夜醒/早醒情况、白天功能（是否开会/看电视就睡着、晨起头痛、注意力差）？
   - 有无**响亮打鼾、憋气/被自己憋醒、同床者目击呼吸暂停**？有任一 → 强烈建议睡眠门诊做睡眠监测排查 OSA。
   - 夜尿次数、睡前饮酒/咖啡/大餐、用药（利尿剂、激素、部分降压/感冒药、镇静药）、情绪与疼痛？
2. **给"睡眠卫生"基础包（先做 2–4 周再谈药）**：
   - 固定起床时间（比固定入睡更重要），早晨晒 10–20 分钟自然光设定生物钟；
   - 睡前 3 小时不进食（与 KetoFLEX 12/3 一致）、不饮酒（酒精破坏深睡）、下午起停咖啡因；
   - 睡前 1 小时调暗灯光、离开手机/电视，卧室凉、暗、静；
   - 规律白天运动但避免睡前剧烈运动；午睡控制在 20–30 分钟内且别太晚；
   - 躺床 20–30 分钟睡不着就起身做安静的事，有困意再回床（重建"床=睡觉"）。
3. **处理 OSA 与夜尿**：疑似 OSA 直接建议家用睡眠监测或多导睡眠图，确诊后规范使用 CPAP/口腔矫治器并减重、侧卧、戒酒镇静药；
   夜尿多需排查前列腺、糖尿病、心衰、利尿剂时间，别简单归因于"老了"。
4. **助眠物质的边界建议**：先问医生/药师；可讨论的包括甘氨酸镁/苏糖酸镁、适量褪黑素（短效、小剂量、适合生物钟紊乱而非万能安眠药）、草本；
   明确提醒长期自行使用苯二氮䓬类、抗组胺类"助眠药"、含镇静成分感冒药反而损害认知，不能自行长期用。
- **完成标准**：用户知道①自己是否有 OSA 红旗并决定是否就医 ②一套可执行的 4 周睡眠行为方案 ③哪些睡眠药有风险。
- **判停条件**：严重日间嗜睡到开车/操作危险、目击长时间憋气伴口唇发紫、新发意识混乱、严重抑郁伴早醒 → 尽快就医。

## B — 边界 (Boundary) ★

- **觉少不等于正常**：老年人睡眠效率下降常见，但长期 <6 小时、片段化或白天功能受损不是"年纪到了"，需查原因。
- OSA 是高风险可逆因素，不能只给"睡前喝牛奶"类建议而漏掉筛查；出现红旗必须优先医学评估。
- 不替代对失眠共病（抑郁焦虑、心衰、慢阻肺、疼痛、前列腺、不安腿综合征、药物）的诊治。
- 处方安眠药（尤其长效苯二氮䓬类、Z 类药、抗胆碱能药）增加跌倒、谵妄与认知风险，停调必须医生指导，不可突然自行停药。
- 褪黑素并非"纯天然就随便吃"：剂量、时间、与抗凝/降糖药相互作用、孕哺与特殊人群需专业评估。
